# Security Policy

**Bintang Studio** takes the security of BSD LiveChat and our users' data with the utmost seriousness.

---

## 1. Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported |
| :--- | :--- |
| `2.0.x` | ✅ Active Security Support |
| `< 2.0` (v1.x) | ❌ Deprecated (Upgrade immediately) |

---

## 2. Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you discover or suspect a security vulnerability in BSD LiveChat:
1. Send an email to **`security@bintangstudio.tech`** or `support@bintangstudio.tech`.
2. Include a detailed description of the vulnerability, steps to reproduce, affected versions, and any proof-of-concept exploit if available.
3. If applicable, encrypt your communication with our security team.

---

## 3. SLA & Response Commitment

* **Initial Acknowledgment:** Within **3 business days**.
* **Triage & Severity Assessment:** Within **5 business days**.
* **Fix & Coordinated Disclosure:** We aim to release security advisories and patches within 14–30 business days, depending on severity and complexity.

In accordance with data protection regulations (including Indonesia's UU PDP), any critical incident involving personal data will be managed under our 3x24 hour incident response procedure.
